# 雷诺曼 V1.1 · 本地冻结版本

在 V2 签到、牌面日历与奖励开发前保存。V1.1 范围：原站框架、八种深度牌阵、手动搓牌、固定自动洗牌、小桌面与无字暗纹牌背、“切牌中”过场、完整解读与附属追问、自然表达的行动建议、“我的主页／充值花瓣／首页”菜单，以及主动开启的真实 DeepSeek 本地测试。

启动：`npm run dev:paid-local:ai`；纯模拟：`npm run dev:paid-local`。只有模型生成调用外部 DeepSeek，本地账户、花瓣与记录使用本机 SQLite。未接真实支付、未切换线上数据库、未部署。

保存命令：`npm run backup:local-v1 -- --version v1.1`。生成代码包、逐文件 SHA-256 清单及单独的本地数据库一致性快照。代码包含未提交文件；密钥、环境配置、测试记录不包含在代码压缩包中。版本备份不等于 Git 提交或 GitHub 推送。

V2 将在当前代码上继续开发；需要回到 V1.1 时，应将 V1.1 代码包解压到新目录，避免覆盖正在开发的 V2。
