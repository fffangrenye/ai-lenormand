# Flora 三万人回馈活动

## 活动规则

- 北京时间 2026-11-23 22:00:00 起，至 2026-11-24 00:00:00 前可领取，共两小时。不是每天重复的时段。
- 进入首页不弹窗；点击首页卡牌动画后，等待约1.6秒再显示。
- 前端向服务端核对时间，00:00自动关闭；后端独立拒绝窗口外领取。
- 新老账号均可领取一次；重复点击、刷新、换设备不会重复发券。
- 全站实际发券上限500张；按确认的要求，弹窗小字保留“限量1000张”。实际限制与显示数量分别配置。服务端在同一事务里扣减名额、写入券，并发领取不会超过500张。领满后显示“本次体验券已领完”；已经领券的账号仍可正常使用，重复领取不占额外名额。
- 未登录先提示登录/注册，返回首页点击卡牌后领取。
- 领取后7天内可使用一次完整洋葱解牌，含九轮解读与最终汇总。
- 券与花瓣分开保存，抽第一张时优先核销券，不扣花瓣。已用券的局可以继续、重试和回看。
- 券过期或已在另一局核销时，原本准备使用券的未开局会报错，不会自动扣用户的花瓣。
- 已领取的账号再次进入首页不重复弹出。活动结束后洋葱页面仍可显示、使用有效券。

## 本地预览

在项目目录运行：

```powershell
$env:PAID_LOCAL_PORT='3110'
node scripts/start-paid-local.cjs --onion-event-preview
```

打开 http://127.0.0.1:3110/ ，点击首页动画。选择模拟账号后回到首页，再点击卡牌即可领取。

此命令使用独立本地数据库、模拟模型与活动内的演示时间，不产生模型费用。演示时间不会进入生产 Worker；正式站只用真实服务器时间。同一测试账号已经领过时，可用另一个本地账号观察首次领取流程。

## 模型成本估算

核价日期：2026-11-23。正式配置为 `deepseek-v4-flash`，官方说明该别名目前按 Flash 价格计费。

官方来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/

| 每百万 tokens，人民币 | 空闲时段 | 高峰时段 |
| --- | ---: | ---: |
| 输入，缓存未命中 | 1元 | 2元 |
| 输入，缓存命中 | 0.02元 | 0.04元 |
| 输出 | 4元 | 8元 |

本次22:00—00:00属于空闲时段，但券可在之后7天使用，预算不能全部按夜间计算。

此前本地日志中的7局完整洋葱，按上述空闲价格重算：每局约0.0195—0.0278元，平均约0.0235元。这些是11月14日测试样本，不是当前提示词的线上实测。

当前代码完整走完一局通常为：9次推荐 + 9次逐张解读 + 1次总结 + 1次开局问题预审，共20次模型请求。每次自定义小问题还会额外预审，最多再加9次；重试另计。

使用正式站当前提示词离线模拟九轮，合计约53,886个输入字符；生成输出上限合计17,830 tokens。字符数不是实测 token 数，也未把全部输出上限当成实际用量。

考虑当前较长提示词、缓存变化、白天使用和少量重试，建议按每局实际完成体验 **0.05—0.15元** 预留模型预算；这是估计范围，不是单局硬性上限。

| 实际完成体验的人数 | 模型预算 |
| ---: | ---: |
| 100 | 5—15元 |
| 500 | 25—75元 |
| 1,000 | 50—150元 |
| 3,000 | 150—450元 |

仅领券不调用模型。领取人数、完成体验人数与注册总量不是同一个口径；中途退出也可能已有少量模型费用。

本次实际最多500人领券，假设全部完成一次，模型预算约25—75元。该范围不是硬性账单上限，重试等仍可能增加费用。

Cloudflare请求、SQLite读写和存储仍有用量。公开时间接口不访问数据库；账号券状态与名额计数采用主键查询，领取写一条券记录并更新一个计数，用券更新一次，避免每次扫描全体用户历史或券表。洋葱本身仍有分步请求和保存进度的读写。付费计划的额度内可能没有额外账单；免费计划仍需关注每日写行和请求限额，不能把“费用低”理解成“不消耗额度”。

Cloudflare计价来源：https://developers.cloudflare.com/durable-objects/platform/pricing/

