# Yes/No 每日三次 · 修改说明

日期：2026-10-30。用户已确认本地效果并授权发布；实际发布状态以正式发布回执为准。

## 修改效果

- 保留原有免登录体验和解读规则。
- 同一浏览器每天可成功抽牌 3 次，北京时间 00:00 重置；刷新页面和点击“再问一个问题”不重置。
- 空问题、过短、过长或不适合 Yes/No 的问题不计次。
- 抽牌输入前、抽牌结果与次数用尽界面均显示三格进度条及“今日 YES OR NO 剩余 X 次 · 北京时间每日零点更新”。完整说明为“YES OR NO功能在升级开发中，为防止用户与开发访问冲突，YES OR NO暂时限量，敬请期待”。
- 第三次结果继续完整展示；次数用完后不再提供“再问一个问题”按钮，保留深度解读入口。
- 次数已用完时重新进入页面，显示额度用完说明和“前往深度解读”按钮，链接 /deep。
- 深度解读仍按原有花瓣规则，限额提示不自动跳转、不自动扣花瓣。
- 计数只保存在浏览器本地，不新增后台统计请求、模型调用或数据库操作；记录不包含问题或牌面。
- 现代浏览器使用 Web Locks 协调多标签页；不支持该能力时仍逐次读取最新本地记录。

## 额度边界

当前是浏览器级限额，不是服务端账号级限额；不同设备、浏览器、无痕会话或清除站点数据可以重新获得次数。该方案用于本地预览和轻量产品限量，不能当作严格的跨设备防绕过措施。
