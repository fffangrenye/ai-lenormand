# 旧站历史补齐到正式站

本次延续已固定的正式站基线，不更换 Supabase 登录身份或 Cloudflare 花瓣账本。仅迁移旧 Supabase deep_projects / deep_readings / deep_reading_cards / deep_follow_up_messages；更早的 projects / readings / reading_cards 表经只读检查为空。

初始统计：9,394 个历史账号、12,410 个项目、55,216 条解读记录、238,864 条牌面记录、25,560 条追问消息。所有账号已验证邮箱，初步归属检查未发现项目或追问错挂。

迁移规则：

- 依据 Supabase 原用户 UUID 关联，新站已有同 ID 内容保留，绝不覆盖。
- 每批每账号独立事务，迁移前后对比花瓣、预留、消费、流水、签到与充值码核销数量；不一致立即回滚。
- 保留源记录全部字段、牌面与追问消息。未完成记录保留原状态，并用明确文案说明未重新生成正文；新站内部将其封存为可读归档，禁止再次解锁或追问，不代表原任务曾成功完成。
- 空正文、不完整抽牌按原样保留，不补牌、不补写解读。JSON 对象字段排序不影响内容比对；数组及原始消息顺序保留。
- 迁移工具和原始导出仅保存在被忽略的私密工作目录，不进入公开仓库。Supabase 原始数据不删除、不修改。
- 正式写入前本地校验全部清单，再做线上只读预检；执行使用短时签名、目标清单和受保护的临时维护通道。完成后删除通道，只提交无用户正文的汇总回执。

验证：归属冲突、重复导入、事务失败、原始字段、未完成状态、空正文、部分牌面、花瓣不变、禁用 AI 解锁、签名失效及跨账号隔离。正常主解读、两次追问、签到和卡密兑换维持原行为。
