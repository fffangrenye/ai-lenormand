# Flora V3.2 · 确认后翻牌

版本日期 2026-11-05。产品版本承接 V3.1。

- 深度解读先洗牌并免费选牌。选满后保留牌背和进度，用户确认使用 1 花瓣后开始解读。
- 服务端在完整解读保存并扣次后返回牌面。生成失败释放预留花瓣，原牌可以重试。已完成的历史解读仍可查看。
- 旧页面发出的自动解读请求缺少确认标识，正式 API 会提示刷新页面。锁定前后使用现有抽牌记录与花瓣事务。
- 本版无需数据迁移或清理。上线验证使用隔离的测试账户及模拟服务，线上只做只读检查。

## 发布与回滚

先发布新版前端 Worker，随后发布 API Worker。发布时记录两个 Worker 先前的版本，并用 Git 标签固定已部署源码。

如需回到发布前，先回滚 API Worker，再回滚前端 Worker。版本 ID 和命令见发布回执。回滚切换运行代码，已保存的解读、花瓣流水和原牌继续留在现有数据库。完成后检查首页、登录、深度解读和 API 状态，并核对两项版本 ID。

回执路径为 [docs/releases/2026-11-05-v3.2-confirm-reveal.json](releases/2026-11-05-v3.2-confirm-reveal.json)。
