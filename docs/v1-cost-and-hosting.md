# 雷诺曼 V1：API 费用与 Cloudflare 部署判断

核对时间：2026-10-21（北京时间）。仅修改本地代码，未部署、未调整线上套餐或数据库。

## API 实测

模型：DeepSeek Flash，关闭思考，使用本地独立体验账号与虚构合作问题。一次完整包为主解读一次＋追问两次，共三次 API 调用。

| 请求 | 输入 tokens | 其中缓存命中 | 输出 tokens | 高峰参考费用（元） |
| --- | ---: | ---: | ---: | ---: |
| 主解读 | 863 | 128 | 554 | 0.00590712 |
| 第一次追问 | 910 | 0 | 101 | 0.00262800 |
| 第二次追问 | 1027 | 640 | 129 | 0.00183160 |
| 合计 | 2800 | 768 | 784 | 0.01036672 |

共 3584 tokens。按本次实际缓存命中与当前官方单价，高峰约 1.04 分，闲时约 0.52 分。只包含模型 API，不包含 Cloudflare、数据库、支付通道等费用。这是一个三牌短背景样本，不代表所有问题和牌阵。

可先给普通三至五牌完整包留 1–3 分的预算，六至九牌留 2–5 分作为暂估余量；并非已验证的费用上限。背景、记忆、追问长度、缓存与时段变化都会改变费用。新请求会把模型返回的真实 tokens 写入 `.local-paid/ai-usage.jsonl`，仅记录阅读 ID、模型、数值用量、耗时及参考费用，不记录问题、正文或密钥。参考价格需随官方调整更新，不是模型账户的扣款账单。

## 与旧版对比

旧版未保留逐次完整 token 账本，不能把估算说成历史实测。

| 版本 | 主解读输出上限 | 每次追问上限 | 含两次追问的总输出上限 |
| --- | ---: | ---: | ---: |
| 旧站三／五牌 | 1400 | 420 | 2240 |
| V1 三／五牌 | 2800 | 420 | 3640 |
| V1 六至九牌 | 3800 | 420 | 4640 |

仅看输出预算上限，完整包约为旧版的 1.63 倍／2.07 倍。实际按生成的 tokens 计费，不是预设上限；输入上下文和缓存也会影响比较。新增牌阵、规则和更详细的主解读会增加用量，搓牌动画本身不调用 AI。

## Cloudflare

新增的搓牌、自动洗牌、牌阵布局在浏览器运行，主要影响用户设备的流畅度，不会在每一帧请求服务器。部署配置已设置静态资源绑定。AI 在 DeepSeek 生成，Worker 主要处理校验、数据读写、请求与返回；等待外部网络不等于持续占用相同长度的 CPU 时间。

当前官方 Workers Free 额度为每天 10 万次动态请求、每次 10ms CPU；Workers Paid 最低 5 美元／月，含每月 1000 万请求及 3000 万 CPU 毫秒，超量另计。静态资源规则与动态请求规则不同，前端一次占卜也不只发一个请求。未核验此账号实时套餐、用量、CPU 与并发，不能据此承诺当前网站的承载人数。

本地 V1 尚不能原封不动上线：本机 SQLite、仅本地开放的账号与补测试花瓣接口都属于测试实现，必须先迁移正式存储并接好正式登录／计费；正式使用应保留账户与 IP 限流、幂等扣除、失败释放、并发控制与用量告警，再在隔离测试环境验证 Cloudflare 构建与负载。此次不做线上改动。

## 本轮体验调整

- 行动建议改为自然段，围绕当下处境说一两件合适的事，不默认布置清单、计时、打卡和复盘任务；追问先答题，确有需要再给做法。仅新生成的内容使用新提示词，历史记录保留。
- 洗牌外框最大宽度从 760 收到 640px，桌面手机高 280px、桌面高 300px。
- 自动洗牌固定为“收牌—分牌—交错—切分—收齐”，手动仍可自由搓牌；减少动态效果设置下保留静态牌堆与进度。
- 洗牌到选牌的过场改为“切牌中”。
- 右上角菜单为“我的主页／充值花瓣／首页”。
