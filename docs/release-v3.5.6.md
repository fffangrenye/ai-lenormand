# Flora V3.5.6 · 全站界面与系统衬线字体统一

本版整合此前在本地确认的页面改动、三牌与五牌阅读方向调整，以及 H 牌阵人物设置。

- 首页、日运与日历、Yes or No、洋葱解牌、深度解读、登录与密码恢复、账户、花瓣购买和兑换页统一排版与控件样式。
- 全站文字使用同一套系统衬线字体，字号保留设备适配；移除未使用的网络字体加载，政策页同步字体。
- 牌阵适用说明保留，详细阅读规则与完整用途说明可展开；AI 生成与娱乐用途摘要仍直接可见。
- 问题保持大标题，追问附在对应解读下，最新解读仍放在下方。
- 三牌与五牌线性解读由用户问题决定组合的解释方向，不再把所有问题强制转为起点、发展、趋势。
- H 牌阵新增我方与对方性别选择，包含不指定选项；信息随抽牌保存并用于人物指代，不改变随机抽牌与七张 H 牌位。
- 价格、花瓣权益、Yes or No 每日限额与签到规则不变；未加入新轮询、埋点或额外 AI 调用阶段。

## 验证

- TypeScript 检查通过。
- 26 个测试文件分别在独立进程运行通过；其中本地端到端测试依赖启动前环境标志，避免与其他测试共享模块缓存。
- H 牌阵新增旧表升级兼容性测试：历史解读、未完成抽牌与花瓣余额保持不变。
- 发布脚本继续执行 Cloudflare 实际运行环境、安全、历史恢复、静态资源和产物密钥扫描检查。

## 发布及回滚

发布前 GitHub 分支必须与源码提交完全一致。前端与 API 分别记录 Cloudflare 版本及发布前版本，最终回执另存 `docs/releases/2026-11-24-v3.5.6-sitewide-ui.json`。

迁移 15 仅为 `paid_readings`、`paid_draw_sessions` 增加 `relationship_json` 字段，默认值为字符串 `null`。旧记录不重写、不重抽、不重新扣次。上一版程序可忽略新增字段，代码回滚不需要删除字段或恢复整个数据库。

本机配置、测试数据库、卡密与用户数据继续排除在 GitHub 之外。
