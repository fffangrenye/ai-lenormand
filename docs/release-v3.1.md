# Flora V3.1 · 用途说明、AI 标识与页面文案更新

版本日期：2026-10-27。本版承接 V3；此前按日期记录的性能维护、框架升级和逐牌日运更新继续保留。这里的 V3.1 是产品版本名，与 Next.js 版本及 Cloudflare Worker 版本号不同。

## 本版范围

- 日运结果与历史弹窗显示娱乐、自我探索及预设文案说明，签到上方不重复展示。
- Yes or No 保留原有解读和深度入口，结果页依次展示结果、原因与下一步入口、用途与内容说明；输入页不增加提示框。
- 深度输入页的说明位于牌阵及选项之后、开始按钮之前；解读与追问显示 AI 标识，每组已保存追问底部展示一条简短用途提示。历史正文不重写。
- 功能名称统一为“每日签到”“深度解读”；菜单、余额入口及套餐页使用“补充花瓣”。更新相关页面标题、社交预览文字、辅助标签与政策中的功能名称。
- 主解读及追问提示明确为“用于娱乐与自我探索的 AI 卡牌解读助手”，保留事实优先、不编造他人内心及确定结局等原有约束。
- 服务条款增加内容用途、服务边界与依法保留责任的说明。提示文案不代表已取得法律意见或平台审核通过。

分享图片、保留的旧界面、路由、定价、支付核销、账户认证、历史数据、牌阵布局、抽牌交互和每日随机签到规则保持原样。没有新增数据库迁移、历史改写或后台统计采集。

## 版本发布与归档

1. 检查源码与构建产物，提交源码并推送 GitHub。
2. 发布前记录前后端当前版本，运行构建、账本、安全、历史及静态页面回归。
3. 将同一源码提交发布至前端与 API Worker，核对线上文件与版本注释。
4. 保存脱敏的发布回执、验证结果和回滚版本；成功后以 `flora-v3.1-20261027` 标签固定本次源码。

本地验证使用隔离数据库及模拟 AI；不使用真实花瓣、充值码或真实 AI 调用作测试。生产日常请求路径不因提示文字增加查询或写入；日报采集继续关闭。GitHub 保存源码，不替代独立用户数据备份；本版不额外打包重复的完整数据副本。

本次实际部署的提交号、Worker 版本、回滚版本及检查结果以 `docs/releases/2026-10-27-v3.1-notices-wording.json` 为准，该回执在发布验证成功后生成。
