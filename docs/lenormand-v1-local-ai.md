# 雷诺曼 V1 · 本地真实 AI 测试

“雷诺曼 V1”指原站框架上完成的本地升级版本，包含八种牌阵、桌面搓牌、自动洗牌、半圆牌扇、无字暗纹牌背、完整解读及附属追问。首页呼吸牌保持原样。

## 打开与运行

- 界面模拟：`npm run dev:paid-local`
- 真实 AI：`npm run dev:paid-local:ai`
- 地址：`http://127.0.0.1:3100/`。同一端口只能运行一个实例，切换模式时先关闭旧的本地服务。

AI 启动命令只读取当前项目 `.env.local` 中的 `PAID_LOCAL_DEEPSEEK_API_KEY`，没有时沿用已有 `DEEPSEEK_API_KEY`。模型优先读取 `PAID_LOCAL_DEEPSEEK_MODEL`，其次是原有 `DEEPSEEK_MODEL`。密钥只交给服务端的专用变量，原站数据库、认证及支付凭据继续清空；不编辑线上配置，不部署。

运行环境使用 Node.js 24。AI 模式启用 Node 的 `--use-env-proxy`，沿用本机已有代理设置访问模型接口，保留正常的证书校验；不更改系统代理设置。

请求固定发送至 DeepSeek 官方 `https://api.deepseek.com/chat/completions`，包含本次问题、原牌位、本站牌阵规则、项目背景与手动保存的长期记忆。追问还会包含本次已保存解读及此前追问。会产生正常的模型 API 用量；不产生真实充值或线上花瓣消费。账户与记录继续使用本机 `.local-paid/v1.sqlite`。

## 如何看效果

进入深度占卜，选择本地体验账号，输入问题、选择牌阵、搓牌／自动洗牌并选满牌位，即会生成真实解读。余额为零时，可点击“补充测试花瓣”；该入口仅在本地出现，只在用完时补 5 个测试花瓣，流水明确标记“本地测试补充（非充值）”。一次性赠送 5 次的正式方案不变。

新结果标记“DeepSeek · 本地测试”；之前的模拟结果继续标记“本地模拟”，不会被重写。只有完整有效的 AI 结果保存成功才消耗本地测试花瓣；失败或超时保留原牌并释放预留，重试已经成功的记录不再次调用模型。真实模式不自动回退成模拟内容。

目前验证是技术连通与保存流程验证，不能代替八种牌阵的质量验收。建议先用固定问题／牌面审阅解读，再逐阵调整规则和样例。

接口格式参考：[DeepSeek 官方 Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。
